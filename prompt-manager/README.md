# Prompt Manager

콘솔 기반 파이썬 프롬프트 관리자입니다.

## 기능 목록
1. 프롬프트 추가: 새로운 프롬프트를 입력받아 저장합니다.
2. 프롬프트 목록 보기: 저장된 전체 프롬프트 목록을 번호, 카테고리, 제목과 함께 출력합니다.
3. 카테고리별 보기: 특정 카테고리를 입력받아 해당 카테고리의 프롬프트만 필터링합니다.
4. 프롬프트 검색: 제목이나 내용에 특정 키워드가 포함된 프롬프트를 검색합니다.
5. 프롬프트 상세 보기: 프롬프트 번호를 입력받아 전체 내용을 구분선과 함께 출력합니다.
6. 즐겨찾기 추가/삭제: 자주 사용하는 프롬프트를 즐겨찾기에 추가하거나 삭제합니다.
7. 즐겨찾기 목록 보기: 즐겨찾기에 등록된 프롬프트만 모아서 출력합니다.
8. Markdown 내보내기: 전체 프롬프트를 각 카테고리별 마크다운 파일로 저장합니다.
9. 인기 프롬프트: 조회수가 높은 순서대로 5개의 프롬프트를 출력합니다.
10. 프롬프트 수정: 기존 프롬프트의 제목, 내용, 카테고리를 수정합니다.
11. 프롬프트 삭제: 특정 프롬프트를 삭제합니다.

## 실행 방법
```bash
python main.py
```

## 카테고리
프롬프트 추가 시 카테고리를 지정할 수 있으며, 지정하지 않으면 '일반' 카테고리가 기본값으로 사용됩니다.
